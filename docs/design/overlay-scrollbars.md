# 共通スクロールバー

全ページで、スクロールできる方向にだけ半透明のつまみを表示します。縦方向は右端、横方向は下端に、見た目の太さ5pxで重ねます。スクロールバー用の余白を取らないため、使えるコンテンツ領域は縦横とも変わりません。つまみの長さと位置は表示領域とスクロール量に追従します。つまみはドラッグでき、ページや各領域のホイール、スワイプ、キーボード入力はそれぞれの既存のスクロール処理で動きます。

ページ本体は画面に固定し、内部のスクロール領域は対象と同じ親要素の中に重ねます。対象は製品一覧の番号トラック、Surroundの技術的仕様、RetreatScreenのアイコン編集、TypeFetchのデモ入力欄、ホームでネイティブ横スクロールに切り替わった場合の製品カード列です。ホーム製品カードの無限ループはEmblaが管理します。内部の領域を追加するときは `data-overlay-scroll` を対象に付け、直近の親要素を絶対配置の基準にします。共通スクリプトが初期化できたページでは、対象となる領域のブラウザ標準バーを非表示にします。

ドラッグ中は対象領域のスナップを一時停止します。Surroundの縦バーをドラッグする間は、説明文の終端から技術的仕様へ自動で移動する処理も一時停止します。

実装は [共通スクリプト](../../site/shared/overlay-scrollbars.js) と [共通CSS](../../site/theme.css) にあります。`npm run test:overlay-scrollbars` で両軸の表示、位置とドラッグ、コンテンツ領域の寸法、内部領域の操作をChromiumとWebKitで確認できます。
