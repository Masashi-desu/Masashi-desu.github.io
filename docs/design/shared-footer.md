# 共通フッター

`site/partials/footer.html` の言語・テーマselectは全ページで共通の構造を使い、各ページの配色へ追従する。

- フォーカス境界線は、そのページが定義する `--accent-color` を使用する。
- フォーカスリングは `--accent-color` を32%の透明度で合成し、境界線と同系色にする。
- ページ固有CSSを持つ製品ページは、ブランドまたは画面UIの主アクセントを `--accent-color` としてbodyへ定義する。
- ライト／ダークで主アクセントが変わるページは、テーマ変更時に `--accent-color` も切り替える。
- RetreatScreen製品ページは背景画像から抽出したライト `#a3e5e6`、ダーク `#ac7be0` を使用する。プライバシー／サポート文書ページはコーラルの文書用アクセントを維持する。

共通フッターへ製品固有の固定フォーカス色を追加せず、`tests/playwright/footer-accent-focus.js` で主要ページのアクセント追従を検証する。
