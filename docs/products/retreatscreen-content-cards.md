# RetreatScreen 製品紹介カード

RetreatScreen製品ページのFeatures、Flow、Tech Specsは、LiquidGLカード内でも情報階層と余白を揃える。

- Featuresカードは連番を表示せず、アイコンの右にタイトル、その下に本文を配置する。
- Featuresの3カードは固定の最小高さを持たず、同じグリッド行の最大コンテンツ高へ揃える。
- Flowの連番は各行の番号列で水平・垂直中央に配置する。
- Tech Specsの「安心して使えるポイント」は、アイコンの右にタイトル、その下に本文を配置する。
- Tech Specsの2列表示では「安心して使えるポイント」に最低31remを確保し、仕様一覧より広く配分して、見出しと日本語の各箇条書きが1行で読める幅を優先する。
- Tech Specsは70rem以下、ほかのカードはモバイル時に1列へ切り替え、同じ情報順序を維持する。
- FeaturesとTech Specsのセクション見出しは、PC表示では説明文をタイトルの下へ置いて同じテキスト列へ揃え、タイトルを1行で表示する。説明文は固定の最大幅や強制改行を持たず、利用可能幅を使ってから自然に折り返す。モバイル表示では横方向のオーバーフローを避けるためタイトルの折り返しを許可する。
- Live Viewはヘッダー内にMac App Storeリンクを置かず、PC表示ではタイトルを利用可能幅へ1行で伸ばす。プレビュー下の説明文も固定の最大幅や強制改行を持たず、利用可能幅を使ってから自然に折り返す。
- Get Ready CTAは、PC表示ではMac App Storeリンクをテキスト列の右下へ置いてタイトル幅を確保し、タイトルを1行で表示する。説明文は固定の最大幅や強制改行を持たず、利用可能幅を使ってから自然に折り返す。モバイル表示ではアイコン、テキスト、リンクの順に1列へ積む。
